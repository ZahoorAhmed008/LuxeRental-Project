# Luxe Clothing Rental Platform 👗

**Affordable • Stylish • Sustainable**

Luxe Clothing Rental Platform is a web application that allows users to rent stylish and premium outfits for weddings, parties, and other special occasions without purchasing expensive clothing.

## ✨ Features

### User Features
- User registration and login
- Browse clothing products with daily rental prices
- View product details
- Submit rental requests through a form
- Add favorite products to a wishlist
- Track rental requests and order status
- Receive activity and status notifications
- View rental policies and applicable late-return fines
- Read fashion-related blog posts
- Contact the admin through messages

### Admin Features
- Admin dashboard access
- Add, edit, and delete products
- Manage product categories, prices, images, and descriptions
- View and manage rental orders
- Accept or reject rental requests
- View rental form details
- Apply fines according to rental policies
- Manage users
- View and reply to user messages

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Authentication:** Firebase Authentication
- **Database:** Firebase Firestore
- **Storage:** Firebase, according to project configuration

## 🔄 How It Works

1. Users create an account or log in.
2. Users browse products and select an outfit.
3. Users submit a rental request with the required details.
4. The request appears in the user's profile and the admin dashboard with a pending status.
5. The admin accepts or rejects the request.
6. Users must return rented outfits within the specified period.
7. Late-return fines are handled according to the platform's policies.

The main objective is to make premium fashion more affordable, encourage clothing reuse, and reduce unnecessary spending and textile waste.
